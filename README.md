## About

This portfolio is a fast, modern, interactive site built with Next.js and TypeScript. It highlights my projects, skills, and background, with smooth animations and 3D visuals to make the experience feel a bit more alive than a static page.

## Features

- ⚡ Built with **Next.js 16** and **React 19** for speed and modern app routing
- 🎨 Styled with **Tailwind CSS** for a clean, responsive design
- 🌀 Smooth scrolling powered by **Lenis**
- ✨ Fluid page and element animations with **Framer Motion**
- 🧊 Interactive **3D visuals** using Three.js and React Three Fiber
- ⌨️ Animated typing effect via **react-type-animation**
- 📩 Working contact form powered by **EmailJS** — no backend required
- 🎯 Icon sets from **Lucide React** and **React Icons**
- 🧹 Linted and formatted with **ESLint** and **Prettier**
- 🌗 Fully responsive across desktop, tablet, and mobile

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/Diyajain3/My_Portfolio.git
cd My_Portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Other scripts

```bash
npm run build   # Create a production build
npm run start   # Start the production server
npm run lint    # Run ESLint
```
